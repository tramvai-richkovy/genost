# GENOST Desktop

Tauri v2, React, TypeScript, Vite, Tailwind, Zustand, and Zod scaffold for the GENOST local music studio.

## Commands

```bash
npm install
npm run dev
npm run tauri:dev
npm run build
npm test
```

`npm run dev` opens the browser-safe shell with an in-memory project. `npm run tauri:dev` is required for native folder selection and project file persistence.
